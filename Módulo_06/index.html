1. Estilos básicos: cores, fontes e seletores

O seletor diz quem recebe o estilo; as propriedades dizem como ele fica. Abaixo, três seletores diferentes atuando em parágrafos.

Parágrafo comum, estilizado pelo seletor de elemento p.

Parágrafo com a classe .destaque.

Parágrafo com o id #aviso.

Também dá para estilizar um trecho dentro do texto.

p { color: #1b2333; font-family: system-ui, sans-serif; }
.destaque { background: #fff3b0; font-weight: 700; }
#aviso { border-left: 4px solid #2748d9; padding-left: 1rem; }
.marca { color: #c2185b; text-decoration: underline; }

2. Classes e IDs

A classe (.nome) pode ser usada em vários elementos. O id (#nome) é único na página e tem mais peso que a classe.

Cartão comum
class="cartao"
Cartão dourado
class="cartao cartao--ouro"
Cartão único
id="cartao-unico"
.cartao { padding: 1rem; border: 1px solid #d9dfeb; }
.cartao--ouro { background: #fff8dc; border-color: #c9a227; }
#cartao-unico { border: 3px double #2748d9; }

3. Box Model: margin, border e padding

Todo elemento é uma caixa com quatro camadas: o conteúdo, o padding (espaço interno), a borda e a margin (espaço externo). 

* { box-sizing: border-box; } /* padding e borda entram na largura */

.caixa {
  width: 300px;
  padding: 1rem;
  border: 4px solid #1b2333;
  margin: 1.5rem auto;
}

4. Layout com Flexbox

O Flexbox organiza itens em uma dimensão (linha ou coluna). Com justify-content e align-items você controla o alinhamento.

5. Organização de páginas com Grid

O Grid trabalha em duas dimensões (linhas e colunas). Com grid-template-areas você desenha a página com nomes.

topo
menu
conteúdo
rodapé
.grid-pagina {
  display: grid;
  grid-template-columns: 1fr 3fr;
  grid-template-areas:
    "topo    topo"
    "menu    conteudo"
    "rodape  rodape";
  gap: .5rem;
}
.gp-topo { grid-area: topo; }

7. Botões interativos com transições

A propriedade transition suaviza a mudança entre o estado normal e o :hover. Passe o mouse (ou use a tecla Tab) sobre os botões. 

.botao {
  padding: .7rem 1.4rem;
  border: 2px solid #2748d9;
  border-radius: 8px;
  cursor: pointer;
  transition: background-color .25s ease, transform .25s ease, box-shadow .25s ease;
}
.botao--primario:hover {
  transform: translateY(-2px);
  box-shadow: 0 6px 14px rgba(39, 72, 217, .35);
}
