1. Organizando o JavaScript junto ao HTML

O HTML cria a estrutura, o CSS cuida da aparência e o JavaScript cuida do comportamento. O jeito mais organizado é manter o código em um arquivo .js separado e ligá-lo ao HTML com a tag <script>. 

<head>
  <link rel="stylesheet" href="estilo.css">
  <script src="script.js" defer></script>
</head>

O atributo defer faz o navegador carregar o HTML inteiro antes de executar o script, então os elementos já existem quando o código tentar encontrá-los. Outra opção é colocar o <script> no fim do <body>. Também é possível escrever o código direto entre as tags, mas misturar tudo dificulta a manutenção.

2. Manipulando elementos da página

Primeiro o JavaScript precisa encontrar o elemento (getElementById, querySelector) e depois alterar o que quiser, como o texto com textContent.

Esta é a mensagem original.

const mensagem = document.getElementById('mensagem');
const botao = document.getElementById('btn-trocar');

botao.addEventListener('click', function () {
  mensagem.textContent = 'O JavaScript trocou este texto!';
});

3. Interações com botões: o evento click

Um evento é algo que acontece na página. Com addEventListener('click', ...) dizemos: "quando clicarem aqui, execute esta função". No exemplo, uma variável guarda o valor e a função atualiza a tela.

0 
let contagem = 0;
const contador = document.getElementById('contador');

document.getElementById('btn-mais').addEventListener('click', function () {
  contagem++;
  contador.textContent = contagem;
});

4. Alterando cor e estilo por eventos

A propriedade style muda o CSS direto no elemento. Já o classList.toggle liga e desliga uma classe que já existe no CSS, o que deixa o código mais limpo.

Eu mudo de cor e de estilo!
const caixa = document.getElementById('caixa-cor');

// vários botões com o mesmo comportamento
document.querySelectorAll('[data-cor]').forEach(function (botao) {
  botao.addEventListener('click', function () {
    caixa.style.backgroundColor = botao.dataset.cor;
    caixa.style.color = '#ffffff';
  });
});

// liga e desliga uma classe do CSS
caixa.classList.toggle('caixa-cor--destaque');

5. Outros eventos além do click

O click é só o começo. Também dá para reagir ao mouse passando por cima (mouseover e mouseout), ao teclado e à digitação (input).

Passe o mouse aqui

Olá, visitante!

const campo = document.getElementById('campo-nome');
const saida = document.getElementById('nome-saida');

campo.addEventListener('input', function () {
  saida.textContent = campo.value.trim() || 'visitante';
});

Resumo da lição

getElementById

querySelector / querySelectorAll
Encontram elementos com um seletor CSS.
addEventListener
Executa uma função quando um evento acontece.
textContent

classList

hidden
Esconde ou mostra um elemento.
defer
